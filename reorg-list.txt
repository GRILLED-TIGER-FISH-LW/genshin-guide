- 色板取 **Claude 官方七色**，几何取 Notion（控件 8px 矩形、卡片 12px、**胶囊只给页签和徽章**）。

  | 角色 | 色值 | 用在哪 |
  |---|---|---|
  | Dark | `#141413` | 主文字（白天）/ 深色页面底（夜间） |
  | Light | `#faf9f5` | 卡片、浅色底 / 夜间主文字 |
  | Mid Gray | `#b0aea5` | 次级元素：需要看得见的边、次要图标 |
  | Light Gray | `#e8e6dc` | 微妙背景：凹槽 `sunken`、`surface-2`、默认分隔线 |
  | Orange | `#d97757` | 主强调 `accent`（按钮、选中态、链接） |
  | Blue | `#6a9bcc` | 次强调 `info` |
  | Green | `#788c5d` | `success` |

- **两个纯色之间不够用的档，只能在这两个纯色之间混**（注释里标比例，如 `canvas` = Light + Light Gray 对半）。手调色相出来的色会发灰发黄，已经全部清掉。
- 调色板没有的两支语义色自己留：`danger` 红（危险操作）、`warning` 黄（取 Orange 的色相压暗），别和 accent 混用。
- **选中态全站一套**：`accent-soft` 垫色 + `accent-strong` 文字（抽屉菜单再加左侧 2px `accent` 竖条）。别拿 `sunken` 当选中色 —— 那是一块灰底，看着像没选中。

## 2026 年 11 月

### 2026-11-21 · 配色对齐 Claude 官方七色；选中态不再发灰；滑块换成「拖动条 + 数字框 + 单位」

- **起因**：侧边菜单里选中的那一项看着发灰，不像被选中；对照 Claude 官方调色板一查，令牌里不少值是手调的中间色 —— 强调色写的是 `#cc785c`（官方 Orange 是 `#d97757`）、凹槽色 `#e8e0d2`（官方 Light Gray 是 `#e8e6dc`）、页面底 `#f5f0e8`、hover `#efe9de`、success 是亮绿 `#5db872`（官方 Green 是 `#788c5d`），而官方的 Blue `#6a9bcc` 干脆没有。
- **经过**：① 令牌全量对齐七色 —— `accent` / `accent-strong` / `accent-solid` / `accent-hover` / `accent-soft` 全部按 Orange 重算，`success` 换 Green，新增 `info` / `info-soft`（Blue）；`canvas` 用 Light + Light Gray 对半，`surface-2` / `sunken` / `line` 用 Light Gray，`line-2` 用 Light Gray + Mid Gray 对半，暗色 `canvas` 用 Dark、`sunken` 提到 `#302d27`（原来和卡片同值，凹槽整片看不见）。调色板没有的红 / 黄留作 `danger` / `warning` 两支。② 选中态固定成一套：`accent-soft` 垫色（12% → 16%，原来太淡等于灰底）+ `accent-strong` 文字 + 抽屉菜单左侧 2px `accent` 竖条；`el-menu` 的 `active-color` 同步；`el-segmented` 轨道用 `sunken`、选中项用 `accent-soft` + `accent-strong`。③ 视频封面 7 个滑块弃用 `show-input`，改「`el-slider` + `el-input-number`（88px）+ 单位文字」三项一行，标签去掉「（px）」「（%）」。
- **结果**：全站强调色、深浅中性、语义色只剩官方七色（外加红黄两支语义色），不再有手调的中间色；侧边菜单、分段菜单的选中项一眼能看出是橙色调的选中状态；凹槽（滑块轨道、分段轨道、折叠底）昼夜都看得见；7 个滑块能直接打字输数值、单位单独显示。约定写进 `AGENTS.md`。
