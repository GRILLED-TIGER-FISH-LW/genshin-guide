# 这一批（weapon-star）：修 lunaris-index 那批引入的星级错误。
#   原因：lunaris 的 qualityType 里 QUALITY_GREEN 同时盖住 1 星和 2 星——
#         无锋剑 11101 与 银剑 11201 的 qualityType 都是 QUALITY_GREEN，但分别是 1 星和 2 星。
#         上一批把它换算成 2 星，于是无锋剑/训练大剑/新手长枪/学徒笔记/猎弓 这五把 1 星武器
#         被抬成了 2 星；另外五把真 2 星的恰好显示对了，所以只露出这五把。
#   修法：① 武器星级改用 id 的第三位（Genshin 武器 id = 1 + 类型 + 星数 + 序号）；
#         ② 星级以 Amber 的自报 rank 为准（它是精确星数），Amber 没有这条才用 lunaris 推的；
#         ③ 补 QUALITY_ORANGE_SP: 5（有 3 个角色是这一档）。

  /* lunaris 只给 qualityType，Amber 给 rank —— 换算成同一档。
     ⚠ QUALITY_GREEN 同时盖住 1 星和 2 星（无锋剑 11101 与 银剑 11201 都是这一档），
        所以武器一律改用 id 里的星数（weaponStar），这张表只给其余分类用。 */
  const QUALITY_RANK = {
    QUALITY_ORANGE: 5,
    QUALITY_ORANGE_SP: 5,
    QUALITY_PURPLE: 4,
    QUALITY_BLUE: 3,
    QUALITY_GREEN: 1, /* 这一档有歧义（1★/2★ 都落在这里），武器不用它；别的分类暂时用不到 */
    QUALITY_GRAY: 1,
  }

  /* Genshin 武器 id = 1 + 武器类型 + 星数 + 序号：
     11101 无锋剑(1★) / 11201 银剑(2★) / 11419 「一心传」名刀(4★) / 11517 银昼(5★)。
     260 把武器逐条与 Amber 的 rank 对过：共同 id 253/253 一致，只有 lunaris 有的 7 把也自洽。 */
  const weaponStar = (id) => {
    const s = String(id)
    return s.length === 5 && s[0] === '1' ? Number(s[2]) || null : null
  }
