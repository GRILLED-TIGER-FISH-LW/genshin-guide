   和「载入在线存档」走同一个 rematchMissing —— 手删过的图有 *Deleted 挡着，不会被补回来 */
async function matchStyle() {
  if (matching.value) return
  if (!s.charName.trim()) return toast.error('请先填角色名')

  matching.value = true
  try {
    await rematchMissing(s)
    toast.success('已按图片字典补齐缺的素材')
  } finally {
    matching.value = false
  }
}

## 2026 年 11 月

### 2026-11-09 · 一图流补回「从字典补素材」

- **起因**：旧版一图流的「外观样式」页有颗「匹配样式图」，一次把立绘 / 元素 / 名片按角色名从字典补上（当时 `tools/character/index.html` 里的 `btnMatchStyle`）。搬进 SPA 时这颗按钮没跟着走，补齐逻辑（`rematchMissing`）只剩「载入在线存档」会叫它 —— 结果是：不先读一份存档，就一点自动补素材的办法都没有，只能自己点图上传。
- **经过**：在「外观样式 → 在线存档」那一行加回一颗「从字典补素材」，位置和名字都按用户定的（旧版这两个按钮就是并排的）。它调用同一个 `rematchMissing`，带 `:loading` 防连点，没填角色名会提示；手删过的图仍由 `*Deleted` 标记挡着，不会被补回来。
- **结果**：不读存档也能一键补齐立绘 / 元素图 / 大背景（连带头像 / 武器 / 圣遗物 / 配队那些缺图）；按钮名字改用页面里的说法，「样式图」这个旧词不再出现在界面上。
