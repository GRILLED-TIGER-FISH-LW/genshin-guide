# 这一批（fix-ident-refs）：修 ident-by-id 那批留下的三个运行时报错。
#   上一批把三个分类的去重识别码改成 ID，但合并逻辑里还剩三处旧写法：
#   ① 头像槽冲突判定还在用 `prev.key !== code` —— code 这轮被删掉了，点「从源匹配」
#      直接 ReferenceError: code is not defined（线上崩的就是这个）。
#      改法：角色的身份是代号，只有角色要判冲突；武器 / 圣遗物 / 怪物的身份是 ID，
#      key 只是拼图用的图标代号，同一个 ID 就是同一条，不存在这种冲突。
#   ② lock 分支把冻结行塞进 merged[prev.key]（代号），而 merged 按识别码（ID）作键
#      → 第 2 遍找不到它，同一条本地行会被再补一遍（重复一行）；改成 identOf(type, prev)。
#   ③ addByName 里 `!f.order` —— f 只存在于 addItem 内部，函数体里没有 f；改成 !row.order
#      （addItem 里 order = f.order || 0，序号表里没有就是 0）。
