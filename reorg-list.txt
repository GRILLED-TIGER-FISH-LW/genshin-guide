# 清单文件：给 .github/workflows/reorg.yml 读的。四段，每段开头一行 == 段名 ==。
#   MOVES    一行一条：旧路径 -> 新路径
#   EDITS    一条一个块：### 文件路径，然后 <<<< 原文 >>>>，再 <<<< 新文 >>>>（原文逐字、在该文件里唯一）
#            —— 这一段里不要写 # 注释行（会被当成文件路径）
#            —— 一个 ### 只能跟一对块；同一文件要改多处，就重复写几遍 ### 路径
#   DELETES  一行一个路径（文件或目录都行）
#   CHECKS   一行一条命令，非 0 即中止
# 跑法：改这个文件 → 提交 → Actions → Reorg → Run workflow（清单名 = 分支名）
#
# 最近一批：fill-fix —— ①控件「凹槽」在某个主题下看不见：暗色 --color-sunken 与 surface 同值，
#   --el-fill-color-dark（滑块轨道/hover）直接等于卡片色；白天 surface-2 与 surface 只差 3/255，
#   segmented 的底几乎看不出。改成掺 faint 的 color-mix，两种主题都能辨。顺带给 segmented 单独设底。
#   ②el-slider 数字框 EP 默认 130px 太宽，收成 72px；7 个滑块标签补单位（px / %）。

  /* EP 的「下沉 / 轨道」填充：tokens 里 surface / surface-2 / sunken 三档差得太小 ——
     暗色下 sunken 与 surface 同值（都 #1f1e1b），滑块轨道和 hover 直接消失；
     白天 surface-2 与 surface 只差 3/255，segmented 的底几乎看不出来。
     掺一点 faint：白天偏灰、夜里偏亮，两种主题下都能看出「这是凹进去的轨道」。 */
  --el-fill-color-dark: color-mix(in srgb, var(--color-faint) 24%, var(--color-surface-2));
  --el-fill-color-darker: color-mix(in srgb, var(--color-faint) 34%, var(--color-surface-2));
  --el-segmented-bg-color: color-mix(in srgb, var(--color-faint) 20%, var(--color-surface-2));
