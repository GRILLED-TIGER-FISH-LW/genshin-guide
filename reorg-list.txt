#   ① 左边列表四个页签都用同一种行（缩略图 + 名字 + No./★/备用源），点一行开右边详情栏；
#   ② 详情栏四个页签共用：头像 / 名片 / 立绘（后两个只有角色有）+ 头像的「用备用源」勾；

#      按代号选中会选错行；同步把身份改掉时收起详情栏。
#   怪物没有星级，详情栏里的星级下拉对怪物隐藏（跟以前一致）。
