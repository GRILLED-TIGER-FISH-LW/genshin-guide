# 清单文件：给 .github/workflows/reorg.yml 读的。四段，每段开头一行 == 段名 ==。
#
# 这一批（monster-namelock）：给怪物加「名字以我为准」的勾。
#   背景：地方传奇在大世界和深渊里名字不一样（西格德 / 历经百战的执灯人），
#         而源只给深渊那个。同步合并时会用源的名字覆盖本地名字（if (item.name) next.name = item.name），
#         所以手填的名字一次同步就冲掉了。
#   改法：加一个只锁名字的字段 nameLock（比现成的 lock 弱 —— lock 是整条冻结，图/星级/序号也不动）。
#         打勾 = 同步不再改这个名字；图、星级、序号照旧跟源走。界面上只在怪物页显示这个勾。
