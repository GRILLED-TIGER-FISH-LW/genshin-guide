## 🚀 开始使用

打开站点后，首页是一张卡片网格，**点卡片进工具，左上角 ☰ 随时切换**。

**不需要登录，不需要填任何个人信息，打开就能用。不会上传任何图片，全部在你手机本地处理。**

| 你想要 | 怎么做 |
|---|---|
| 做一张角色攻略封面 | 进「封面制作 → 视频封面」，选「角色攻略」模式，第二行填角色名 |
| 做一张世界 Boss 封面 | 同上，切到「Boss攻略」模式，第一行填 Boss 名 |
| 做一张角色攻略一图流 | 进「角色一图流」，九个分区依次填；填完点底部「导出图片」 |
| 做一张合集封面 | 进「封面制作 → 合集封面」，上传背景图 + 填标题 |
| 维护图片字典 | 进「图片字典编辑器」，一键从 Amber 同步 |
| 换手机、换浏览器 | 先导出配置 / 存档，到新设备导入（见[数据保存](#save)） |
| 夜间使用 | 点右上角图标切换深浅色 |

首次打开会自动跟随系统主题，之后按你的选择记住。

## 🎴 角色一图流

九个分区，一次只显示一个（点上面那排按钮切换），预览常驻在上方：

| 分区 | 内容 |
|---|---|
| 外观样式 | 角色名 / 版本 / 日期 / 作者、元素配色、字体、载入在线存档 |
| 立绘 | 立绘、元素图、大背景，以及立绘左右偏移 |
| 武器 | 毕业 / 可选 / 新手三组，每组最多 4 把，组内可收起展开 |
| 圣遗物 | 整套（一个图标）与散搭（两个图标并排） |
| 天赋 / 词条 / 面板 / 命座 | 加点、主副词条、面板数值、六个命座（点圆圈点亮） |
| 配队 | 1 号位头像 + 最多三支队伍，每队 2/3/4 号位主角色与最多 4 个备选 |

- **名字要去匹配图标**：输入框**失焦（点别处）后**才会去图片字典取图，取不到就是灰底占位。
- **草稿自动保存**：改动后停手约一秒会写进本机，下次打开接着上次。
- **载入在线存档**：按角色名去仓库里找（编号取自图片字典）；当前仓库里只有芙宁娜、爱可菲、丝柯克、瓦列里、米提亚五份。载入后缺的图会自动从字典补齐。
- **字体只作用于这张卡**，清单与视频封面共用（`public/fonts/`）。
- 底部悬浮的「导出图片」= **3840×2160 PNG**；右上角三个浮动按钮是导出配置 / 导入配置 / 清空，**点预览空白处可以淡出**。
- 从存档 / 配置载入时，**你手动换过的图、手动删过的图不会被自动覆盖**。

## 🖼️ 封面制作 · 视频封面

### 三种模式

| 模式 | 做什么 | 你要填 |
|---|---|---|
| **角色攻略** | 自动配编号 + 立绘 + 名片图 | 第二行填**角色名** |
| **Boss攻略** | 自动配怪物图标 | 第一行填 **Boss 名** |
| **自定义** | 全部手填，可加浮动素材 | 主标题 / 副标题 / 标签文字 |

切模式会弹确认框 —— 因为**会清掉背景图、立绘、Boss 头像**，别误点。

### 操作

- **预览框右上角**四个按钮：参考线、导出配置、导入配置、清空。
- **点预览空白处**可以把右上角那排按钮淡出，看清整张图；再点一下回来。
- **名字要在输入框失焦（点别处）后才会去匹配**，匹配不到会弹提示。
- 立绘位置、背景亮度、背景模糊、标签文字亮度都是滑杆，**右侧数字框可以直接输入精确值**。
- 自定义模式可以加多张「浮动素材」，每张能调 X 位置 / 缩放 / 圆角，以及放在模糊层上方还是下方。

### 导出

- 底部悬浮的「导出图片」= 3840×2160 PNG。
- **字体只作用于导出的图**，导出时字体会被内嵌进图片，换设备也不会变。
- 导出文件名取「第二行 → 第一行 → 主标题」，后面跟当天日期。
- 配置可以导出成 JSON（不含字体数据，体积小），换设备时用它恢复。

## 🖼️ 封面制作 · 合集封面

- 2560×1440，背景图会自动模糊（模糊度 / 亮度可调），并做边缘拉伸防漏底。
- 主标题白色、副标题浅金，整块自动垂直居中；单行太长会自动缩字号。
- 右上角一个清空按钮，点预览空白处同样会淡出。
- 草稿自动保存，下次打开还在。

## 🔤 图片字典编辑器

- **一键同步**：从 Amber 拉最新数据，合并进本地字典。
- **硬规则**（武器非五位数 / 28 开头怪物 / 官方旅行者图）会跳过并记进「跳过」，同时清掉本地同 key 的条目；**软规则只加不删**。
- **粘贴 URL** 会自动补名字、星级、序号。
- **导出 `image-dict.js`**：格式被两个仓库读取，改动前想清楚。
- 有未导出的改动时，导出按钮会变红提醒。

> 字典里现在存着角色的**头像 / 名片 / 立绘**三样，以及圣遗物 / 武器 / 怪物图标，是全站图片的唯一真源 —— 角色一图流与封面工具都从这里取图，序号也从这里取。

## 💾 数据保存

**全部存在你这台设备的浏览器里，不会上传到任何服务器，也不会跨设备同步。**

| 内容 | 存在哪 |
|---|---|
| 图片字典编辑器的编辑内容 | 浏览器本地存储（`icon_dict_editor_v4`） |
| 角色一图流草稿 | 浏览器 IndexedDB（`genshin_card_db_v5` → `card_store`） |
| 视频封面配置 | 浏览器 IndexedDB（`video_cover_db` → `video_state`） |
| 合集封面配置 | 浏览器 IndexedDB（`video_cover_db` → `collection_state`） |
| 深浅色选择 | 浏览器本地存储 |

> ⚠️ 封面的「清空」与一图流的「清空全部数据」都是**立即生效且不可撤销**的，里面有二次确认；清空前建议先「导出配置」备份。
> 换手机时：封面与一图流用**导出配置 JSON** 搬，图片字典用**导出 `image-dict.js`** 搬。

<a id="faq" name="faq"></a>
## ❓ 常见问题

**换了大字体，导出的图里还是默认字体？**
字体要等下载完（下拉旁会显示「正在加载…」）。如果显示「字体加载失败」，重新选一次即可；也可能是那个字体文件本身有问题。

**导出的图能和预览一模一样吗？**
能。预览和导出用的是同一份画面结构，不存在「预览好导出坏」。

**封面导出的图很大？**
视频封面是 3840×2160、角色一图流也是 3840×2160，几千 KB 是正常的。合集封面是 2560×1440。

**我选的图片会上传吗？**
不会。图片只在你的浏览器里用 Canvas 处理，不经过任何服务器。

**一图流的「载入在线存档」怎么只有几个角色？**
存档放在仓库的 `public/saves/characters/`，按角色名找（文件名里的编号取自图片字典），目前只有五份；没有的那些自己填一次，草稿会自动留着。

**为什么有几个工具长得不一样？**
那几个还没搬到新界面（见上面的🟡）。功能都是好的。

**清空缓存后草稿没了？**
会没。清空浏览器数据 = 删掉本机草稿；重要配置建议导出成 JSON 存别处。

## 📁 项目结构

    genshin-guide/
    ├── index.html                入口（主题预置 + 加载守卫 + 旧链接归一）
    ├── src/                      页面与控件
    │   ├── styles/               设计令牌 + 全局基线
    │   ├── components/           通用控件（按钮 / 输入 / 下拉 / 弹窗 / 预览框 / 底部主操作…）
    │   ├── composables/          主题 / 提示队列 / 数据加载 / 图片字典
    │   ├── lib/                  纯引擎：绘制导出 / 草稿存档 / 字体 / 资源
    │   └── views/                页面（首页 / 角色一图流 / 图片字典 / 两个封面）
    └── public/                   整个目录原样搬到网站根
        ├── shared/               真共享的两样：UI 图标库 + 图片字典与加载器
        ├── tools/                还没搬进新界面的 3 个旧工具页
        ├── data/                 只剩 logos.txt（角色数据已并入图片字典）
        ├── fonts/                字体库
        ├── images/               本地素材
        └── saves/characters/     角色一图流的存档

> 想改代码的话，先看 [AGENTS.md](./AGENTS.md)（协作流程、实现约定、诊断套路）和 [CHANGELOG](./CHANGELOG.md)（里程碑）。
